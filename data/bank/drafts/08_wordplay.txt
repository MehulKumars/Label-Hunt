# HOW TO READ THIS FILE
# - Members are listed core first; words that already live in the bank come after the core and are there because
#   they honestly satisfy the rule (declared crossings). Hidden-word categories are long for that reason.
# - "Hidden X" means X appears as consecutive letters inside a longer word (sHINe, cHAIR). A word that simply IS
#   an X (Palm, Lime) is not a hidden X; pair rules keep the direct source categories out of the level anyway.
# - Every family below is mutually paired (see PAIR lines at the end), so sibling overlaps never meet in a level.
# - "# TARGETS" lines list the exact words each hidden/anagram rule looks for, so the merge step can rescan
#   the merged bank mechanically (substring for hidden, sorted letters for anagrams).
