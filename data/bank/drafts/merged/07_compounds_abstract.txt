# SUMMARY
# ---------------------------------------------------------------------------------------------------------------
# Counts: 85 new categories.
#   Tier 3: 62 (60 compounds, all domain lateral: 30 "Words before X" + 30 "Words after X"; plus Things that buzz
#           and Squeaky things, domain abstract).
#   Tier 2: 23 (abstract properties, plus Virtues as one abstract concept group).
#   Tier 1 and 4: none.
#   Extensions: 7 existing compound categories (+words_before_ball/board/cake/fish/house, +words_after_fire/sun)
#   and 40 other bank categories, to declare crossings.
#
# How crossings were built: each compound key was brainstormed exhaustively. Every strong compound whose first or
# second word appears anywhere (a card in this file or any bank word) is listed in that category, so overlaps
# between the compound categories themselves are declared. Moderate compounds were left out on purpose, both as
# members and as declarations: snowline, treeline, waterside, wayside, headroom, tearoom-style "X room" variants,
# boatman, seaman, footman, iceman, lamplight, sidelight, backlight, fog lamp, hotbed, hot pepper, firebreak,
# summerhouse, soundboard, storyboard, sandfly, cheeseboard, breadboard, soapstone, dustproof, backbite, bookplate.
# A player could still think of one, but none is top of mind.
#
# Biggest crossing words (all declared): Fire (14 categories), Water, Ball (11), Light (10), Snow (9), Star, Bed,
# Back (8), Ice, Time, School, Line, Fly (7).
# Fun cross-domain herrings: Drum (instrument, stick, ear, loud), Sandal (footwear, wood), Pea (vegetable, coat),
# Kidney (organ, bean), Vanilla and Coffee (ice cream, bean), Radish (vegetable, horse, roots), Chestnut (nut,
# brown, horse, water), Buffalo (safari, water), Lily (flower, water, day), Polo (sport, water), Lime (citrus,
# green, light, stone, sour), Patience (card game, virtue), Castle (chess, sand), Swing (dance, music, squeaky),
# Country and House (music genres), Mile (unit, stone), Curling (winter sport, stone), Bow (tie, rain),
# Whip (crack, horse), Neon (gas, glow), Crayon (art, melt), Glacier (landform, melt, slow, cold), Skunk (stripes,
# smelly), Web (animal home, sticky), Bubblegum (pink, sweets, sticky, stretchy), Jet (gem, loud), Coral (pink, rough),
# Club (golf, night, book), Shop/Zoo (town), Pigsty/Barn (animal homes).
#
# Non-lateral extensions, and why: body_parts gets Hand, Head, Leg, Arm, Jaw, Shin, Finger, Back, Hair because the
# compounds use them constantly. Weather gets Storm, Cloud, Blizzard, Tornado. Things you wear gets Gown, Tights,
# Leggings, Suit, Tie, Wig, Fleece. Each other + line adds a word this file uses that a player would accept there.
#
# Words deliberately avoided:
#   - Cards that contain another category's key, which would leak it: Firework (fire+work), Windmill, Sandpaper,
#     Snowflake, Snowman (with Snow), Iceberg (with Ice), Teacup, Landfill, Shot (hotshot has "hot" inside), Breaker
#     (with Break), Lifebelt.
#   - Regional words: Motorway and Freeway (Free is kept only as a declared crossing), Sidewalk and Crosswalk (so no
#     "Words before walk"), Windshield, Head teacher, Headmaster, Eggplant, Raincheck, Snow pea, Snow day, Worktop,
#     Stovetop, fruit "stones", Runner bean, Broad bean, String bean, Wicket. Rubber is out (UK eraser).
#   - Spelling and length: Chilli, Yoghurt, Gooseberry (10 letters), Crepe (accent varies).
#   - Taste: Dead (deadline), Headstone, Gravestone, Kidney stone, Gun, Sword, Bomb, War and Battle compounds,
#     Watergate, Homebrew, Bum bag, Nightmare, Roadkill.
#   - Disputes: Rhubarb (fruit or vegetable), Diamond (clashes with the Diamonds suit), Rock (Rocks label), Koala
#     kept only in Slow things.
#   - Gum is out; Bubblegum is used instead, so it declares the crossing with Shades of pink.
#
# Keys dropped as too generic or too promiscuous (they would need 20+ declared members):
#   - before line (base, side, neck, hair, bee, time, land, under, guide, waist, phone, front all qualify);
#   - before bag, box, pot, cup, bowl, brush, bell ("X bag" is open-ended: laptop bag, golf bag...);
#   - after black, blue, sea ("black tea", "sea turtle" and so on are endless colour or place adjectives);
#   - after ice (needs both Skate and Skating); Round things, Invisible things, Cold-only things.
#
# Accidental substrings kept, because they carry no clue: Rain/Brain, Air/Stair/Fair, Pot/Spot.
#
# Unsure, least sure first:
